# S-45: Playtest with 5 people

- **Priority:** P1 (milestone M7 Release MVP)
- **Covers:** NFR-14 · **Decisions:** Q-05, Q-09, Q-11
- **Depends on stories:** S-41

## User story
As the stakeholder, I want 5 friends to play the game and give feedback, so that real problems become new issues.

## Acceptance criteria
1. **Five players**
   - Given a working local or later-deployed version
   - When the stakeholder runs the playtest
   - Then 5 people each play at least one full match
2. **Feedback recorded**
   - Given the sessions
   - When they finish
   - Then each piece of feedback is written down
3. **New issues**
   - Given the feedback
   - When it is reviewed
   - Then actionable items are created as new issues

## Out of scope
- Deploying the game (the stakeholder does that outside the board, Q-11).

## Notes
- The stakeholder organizes and runs this with friends (Q-05); the board item tracks it.
- Board priority P1 here is an ordering hint only.
