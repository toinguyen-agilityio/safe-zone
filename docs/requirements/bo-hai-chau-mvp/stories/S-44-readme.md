# S-44: README with introduction, controls and how to run locally

- **Priority:** P1 (milestone M7 Release MVP)
- **Covers:** NFR-11, NFR-14 · **Decisions:** Q-04, Q-11 (local only)
- **Depends on stories:** S-38

## User story
As a friend of the stakeholder, I want a README that explains the game and how to run it, so that I can try it on my own computer.

## Acceptance criteria
1. **Introduction**
   - Given the README
   - When I read it
   - Then it describes the game and includes screenshots
2. **Controls**
   - Given the README
   - When I look for keys
   - Then all controls are listed and match the game
3. **Run locally**
   - Given a fresh clone
   - When I follow the README steps
   - Then the game starts in Chrome
4. **No deploy instructions**
   - Given the README
   - When I read it
   - Then it does not promise a hosted link

## Out of scope
- Deploying to the web (outside the board, Q-11).

## Notes
- Board priority P1 here is only an ordering hint; it is unrelated to the plan's P1 requirements.
